# 📊 Overview
This project presents an interactive Sales Performance Dashboard built using the Superstore dataset.
The dashboard provides insights into sales trends, category performance, regional distribution, and key business metrics.

# 🎯 Objective
To analyze sales performance and identify key drivers of revenue, profitability, and growth across different dimensions.

# 🛠 Tools & Technologies
* Tableau
* Excel (Data Source)

# 📸 Dashboard Preview
https://github.com/nehakatkar1398/tableau-sales-dashboard/blob/0f8138ce10477f860c4277087279b8632d5e7263/Sales_Performace_Dashboard.png

# 📈 Key Features
* KPI Cards for Sales, Profit Margin, and Return Rate
* Sales analysis by Category and Sub-Category
* Regional sales distribution using Map
* Segment-wise sales contribution
* Monthly Sales Trend analysis
* Top 5 Products by Sales

# 🔍 Key Insights
* Technology is the top-performing category contributing the highest share of sales
* Consumer segment dominates overall sales performance
* Certain states like California contribute significantly to total revenue
* Sales show consistent growth over time, especially after 2016
